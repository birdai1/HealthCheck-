# HealthCheck-
HealthCheck is a fast, minimalist daily health check that converts a few core inputs into a single, shareable score.
Most health apps overwhelm users with metrics they don’t act on. HealthCheck does the opposite: it prioritizes speed, consistency, and adherence over depth.

Why this exists
People don’t fail to improve because they lack information.
They fail because tracking is too heavy to sustain.
HealthCheck is designed to be completed in seconds so it can be done every day, not just on motivated days.

How it works
User inputs a small set of daily signals (e.g. sleep, movement, nutrition)
Inputs are normalized into a simple score
The score provides immediate feedback without analysis paralysis
Results can be shared or tracked over time
The goal is not precision—it’s behavioral consistency.
Tech Stack, HTML, CSS, JavaScript (Deliberately lightweight to prioritize speed and iteration.)

Current Status
This is an early prototype focused on validating the core interaction:
ultra-low friction input
immediate feedback
repeat daily use
Future iterations may explore persistence, trends, and integrations once core behavior is proven.

Philosophy
HealthCheck is built on a simple belief:
Systems beat motivation.
If a habit can’t survive low-energy days, it’s not a real habit.
